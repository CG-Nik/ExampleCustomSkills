# ExampleCustomSkills
This mod can be used an example for modders to add custom skills to the game using a mod.  
Custom skill mods need to be on both the Client and the Server to work properly.  
Custom skill mods require that you have https://github.com/CG-Nik/CustomSkillsAPI downloaded for them to work properly.  
https://github.com/CG-Nik/HandOnSideStructurePatch can be added as a dependency to a custom skill mod if it uses HandOnSideStructure.  

If you want an example for how to handle how players should download a mod with AssetBundles, you can look at https://github.com/CG-Nik/StingerReadded/tree/master.  
In general, StingerReadded can be used a secondary reference for how to add custom skills.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
